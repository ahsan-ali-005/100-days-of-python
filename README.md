# 🐍 100 Days of Python

A complete Python learning journey where I practice Python every day by solving problems, building mini-projects, and exploring core programming concepts.

This repository documents my progress as I work through **100 Days of Python**, starting from Python fundamentals and gradually moving toward object-oriented programming, file handling, modules, and real-world projects.

The purpose of this repository is to:

* Practice coding consistently every day.

# 🚀 How to Run the Projects

## 1. Clone the Repository

```bash
git clone https://github.com/ahsan-ali-005/100-days-of-python.git
```

## 2. Navigate to the Repository

```bash
cd 100-days-of-python
```

## 3. Open Any Day Folder

Example:

```bash
cd Day-15
```

## 4. Run the Python File

```bash
python filename.py
```

or

```bash
python3 filename.py
```
